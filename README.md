# Data-Structures-And-Algorithms
This project is the culmination of my Data Structures and Algorithms course. This project helped in my preparation to understand and implement organized data structures and complex algorithms. These help to facilitate intentional and engaged performance standards within my software. 

What was the problem you were solving in the projects for this course?
The projects of this course revolved around implementing code that can handle the intake, sorting, retrieval, and printing of data. Specifically, this project sought to intake a CSV of Computer Science courses and their dependencies, and then the program had to sort the courses. After sorting, the user would be able to search and print as needed.

How did you approach the problem? Consider why data structures are important to understand?
For the purposes of solving the issue of which data structure to choose, we have to understand the benefits and drawbacks of each data structure. By reviewing the Big O notation time, we can generalize the time and space complexity and arrive at the option that provides are system with as little bloat as possible. 

How did you overcome any roadblocks you encountered while going through the activities or project?
Throughout the duration of this course, I was juggling a career, homeschooling my two sons, and aiding with the birth of our third child. Time management, and listening to videos and watching visualizations of the different algorithms aided tremendously in recognition of the respective data structure traits. I also would attempt to explain them to family members to see if I could simplify them enough to understand them myself.

How has your work on this project expanded your approach to designing software and developing programs?
Going forward, I have a stronger foundation with planning my internal structures to handle scalable amounts of data. The ability to locate, traverse, and sorted as needed for a more optimal product. 

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
These project have improved my competencies with building structured and readable pseudocode. I also recognized the project requirements and adapted our code to ensure it meets the needs of our program.
